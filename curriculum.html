GICS Curriculum

Free computer science lessons, built by GICS and made to last past any one graduating class

Every year GICS runs workshops, but workshops end when the people who ran them graduate. This page is our attempt to fix that: a small, growing library of self-paced lessons that any GICS officer can hand a new member on day one — no laptop setup, no prior experience required. Each course pairs short lessons with a hands-on assignment students submit for feedback.

Intro to Python

A 4-part course for complete beginners — no installs, just a browser

Course 1 of many

Learn to code by building small, real programs. Every lesson runs entirely in the browser using Replit, so there's nothing to install. By the end you'll have written a personal intro program, a Mad-Libs generator, a grade calculator, and a number-guessing game.

Lesson Topic You'll build
1 Hello, Python! A "Personal Intro" program
2 Talking to Your Program A Mad-Libs generator
3 Making Decisions A grade calculator
4 Loops & Functions A number-guessing game (capstone)
