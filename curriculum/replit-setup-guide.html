Setting Up Replit

Before Lesson 1 · takes about 5 minutes

Goal: create a free account and know your way around the workspace

All four Python lessons run on Replit, a free website that lets you write and run Python code with nothing to install. You just need an internet connection and an email address (or a Google account).

1. Create your account

  1. Go to replit.com and click Sign up in the top-right corner.
  2. Pick the fastest option for you — Continue with Google if you have a Google or school Google account, or sign up with your email address.
  3. Fill in a username and, if asked, confirm your email address by clicking the link Replit sends you.
  4. If Replit asks what you're using it for, "Learning to code" / "Student" is a fine answer — it doesn't change anything you can do.

2. Create your first Python Repl

A "Repl" is just Replit's name for one coding project.

  1. From your dashboard, click the + Create Repl button.
  2. In the template search box, type Python and select it.
  3. Give it a name that describes what you're building, e.g. lesson-1-personal-intro — no spaces, use hyphens instead.
  4. Click Create Repl. Replit will open your new workspace.

3. Find your way around the workspace

You'll mainly use three areas:

AreaWhat it's for
Editor (center)Where you type your Python code, in a file usually called main.py
Run button (top)The green button that runs your code
Console (right or bottom)Where your program's output appears, and where input() prompts show up

Type print("Hello, world!") in the editor and click Run. You should see Hello, world! show up in the console within a few seconds.

4. Get your shareable link

Every assignment asks you to submit a link to your Repl, so it's worth doing this once, carefully:

  1. Click the Share button near the top of the workspace.
  2. Make sure the visibility is set so that anyone with the link can view it (Replit's default sharing is fine — you don't need to make it "public" in the community sense).
  3. Copy the link and paste it somewhere safe, like a notes app, until you're ready to submit.

Your work saves automatically as you type — there's no separate "save" button to remember.

Troubleshooting

  • Nothing happens when I click Run. Make sure you're editing main.py (the file tab should be highlighted), then try Run again.
  • I typed something and the program is stuck. If your code uses input(), click into the console area and type your answer there, then press Enter.
  • I can't find my Repl again. Go to replit.com/~ — that's your personal dashboard of everything you've created.

Note for future GICS officers: this guide is written to stay useful even if Replit's interface changes slightly over time. If you'd like to add screenshots for each step, drop the images into the images/ folder and reference them in this file — that's all it takes to keep this current.
