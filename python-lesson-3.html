Making Decisions

Intro to Python · Lesson 3 of 4

Goal: make your program choose different paths based on data

Booleans and comparisons

A bool is either True or False. You get one any time you compare two values:

print(5 > 3)    # True
print(5 == 3)   # False
print(5 != 3)   # True
Operator Meaning
==equal to
!=not equal to
> / <greater / less than
>= / <=greater/less than or equal to

Common mistake: = assigns a value, == compares two values. Mixing them up is one of the most common beginner bugs.

if, elif, else

An if statement runs a block of code only when a condition is True. Notice that the indented lines are what "belongs to" the if — Python uses indentation (not curly braces) to group code.

age = int(input("How old are you? "))

if age >= 18:
    print("You're an adult.")
elif age >= 13:
    print("You're a teenager.")
else:
    print("You're a kid.")

Python checks each condition top to bottom and runs the first one that's True, then skips the rest. else catches everything that didn't match.

Combining conditions

Use and, or, and not to combine multiple checks:

age = 16
has_id = True

if age >= 16 and has_id:
    print("You can get a driver's permit.")

if age < 13 or age > 19:
    print("You're not a teenager.")

and requires both sides to be True; or only needs one.
